# RustDesk Panel

Собственная панель управления устройствами для RustDesk Server OSS.

> **Статус:** начальная разработка. Проект не является RustDesk Server Pro и пока не управляет доступом на уровне HBBS/HBBR.

## Цель

Создать самостоятельную систему администрирования для существующего RustDesk Server OSS:

- каталог устройств с группами, названиями, заметками и поиском;
- синхронизация доступных метаданных с HBBS;
- пользователи, роли и аудит действий панели;
- мониторинг устройств и история подключений при наличии достоверного источника событий;
- в перспективе — совместимый API адресной книги и централизованные политики доступа.

## Начальная инфраструктура

- **Платформа:** Synology DSM, Docker Compose.
- **Действующие контейнеры:** `HBBS` и `HBBR`. Их конфигурацию и сетевые порты не изменяем.
- **Хранилище HBBS:** `/volume3/docker/rustdeskhbbs`.
- **Хранилище HBBR:** `/volume3/docker/rustdeskhbbr`.
- **Сеть:** `rustdesktop_rustdesk-net`.

Пути являются параметрами развёртывания, а не обязательными настройками для других пользователей.

## Архитектура

```text
RustDesk clients ↔ HBBS / HBBR  (существуют независимо от панели)
                      │
                      │ только чтение разрешённых метаданных
                      ▼
              Inventory exporter
                      │
                      ▼
                 RustDesk Panel
              Web + API + БД панели
```

В первой версии панель работает **независимо** от HBBS/HBBR. Остановка панели не должна препятствовать существующим сеансам RustDesk.

## Границы первой версии

Наша панель может хранить собственный реестр устройств, группы и заметки. **Наличие записи в базе HBBS не доказывает, что устройство сейчас онлайн.** Роли внутри панели **не ограничивают** подключения самого RustDesk. Для таких функций потребуется отдельная интеграция с сервером и/или клиентами.

## Безопасность

- Нельзя публиковать `id_ed25519`, `id_ed25519.pub` вместе с приватным ключом, `*.sqlite3`, реальные адресные книги, токены, пароли, `.env`, `admin-password`, личные данные устройств.
- Код проекта и контейнеры панели не должны менять работающие HBBS/HBBR и их ключи.
- Не выставлять административную веб-панель напрямую в интернет до внедрения TLS, защиты входа, аудита и проверки безопасности. Предпочтительно открывать через VPN.
- Не выполнять операции записи в БД HBBS из панели.
- Не переносить базу устройства или ключи RustDesk в GitHub.
