# RustDesk Panel

**MVP 0.2:** независимая веб-панель управления устройствами для RustDesk Server OSS. Работает рядом с HBBS/HBBR, не меняет их конфигурацию и ключи.

**[Установка на Synology DSM](docs/INSTALL.md)**

## Что работает

- Авторизация администратора с PBKDF2-SHA256, сессиями и защитой форм от CSRF.
- Чтение метаданных из базы SQLite HBBS только в режиме read-only.
- Каталог RustDesk ID с собственными названиями, группами, заметками и поиском.
- Ручное добавление ID, в том числе при отсутствии данных от HBBS.
- Избранное, фильтр по группе и массовое назначение групп.
- CSV-экспорт списка устройств и заметок с защитой от выполнения формул при открытии файла.
- Отдельная база SQLite для конфигурации панели.
- Два независимых контейнера Docker: exporter без сети и web без прямого доступа к HBBS.

## Установка

Для Synology с HBBS в `/volume3/docker/rustdeskhbbs`:

1. Скачать ZIP из публичного репозитория на компьютер или прямо на NAS с помощью wget.
2. Распаковать в `/volume3/docker/rustdesk-panel`.
3. Скопировать `.env.example` в `.env`.
4. Создать каталоги `state`, `shared` и секретный файл `admin-password` с правильными правами.
5. Запустить `docker compose -f compose.yaml up -d`.
6. Открыть `http://192.168.30.150:8765` из доверенной LAN/VPN.

**Для уже работающего экземпляра обновлять только код по [UPGRADE.md](docs/UPGRADE.md).**

**Точные команды первоначальной установки и проверки прав в [INSTALL.md](docs/INSTALL.md).** Не запускайте до выполнения его шагов по подготовке каталогов и пароля.

## Локальные тесты

```sh
python3 test_local.py
```

Тесты также настроены в GitHub Actions.

## Важно

- Онлайн-статус, история реальных сеансов, централизованная адресная книга клиентов RustDesk и применение политик доступа **не реализованы**.
- Никакие данные в базу HBBS не записываются.
- Не открывать порт панели в интернет: текущая версия использует HTTP, доступ только в доверенной сети или через VPN.
- Не загружать в Git ключи RustDesk, настоящие базы SQLite, файлы `.env` и `admin-password`, списки реальных устройств.
- Действующие HBBS/HBBR не зависят от панели.

Это самостоятельный проект и не коммерческая версия RustDesk Server Pro.
